# Gatekeeper Admin Dashboard

React + Vite admin dashboard for the Gatekeeperd API.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Dev server proxies `/api` to `http://localhost:8080`.

## Stack

- React 19, TypeScript, Vite
- Tailwind CSS 4, shadcn-style UI components
- React Query, Zustand, React Router, Axios
